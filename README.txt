PUBBLICAZIONE SU GITHUB PAGES
Carica tutto il contenuto della cartella nella radice di un repository,
poi Settings > Pages > Deploy from a branch > main / (root).

FILE
- index.html, privacy.html, cookie.html: le tre pagine
- style.css: stile (modalita' scura e chiara)
- theme.js: pulsante scuro/chiaro (scelta salvata sul dispositivo)
- fx.js: sfondo animato a scariche (canvas, leggero)
- media/: foto del carosello (vedi media/LEGGIMI.txt)
- assets/: logo, icona della scheda, font
